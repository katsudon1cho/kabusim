## 7. 自分の判断で間違っていたと思う点

### 1. SPGI の答えは、自分が同じセッションで書いたメモの3節上にありました

昨日の us-close で、私は **§5 に「NFLX +5.3% — Ackman の 315万株」と書き、その3節上の
§3 に「SPGI +3.3% — 理由を特定できていません」と書いています。同じ1つの開示です。**
Pershing Square の Q2 レターは NFLX・SPGI・V・MA・ICE・Alcon の6件を同時に開示していました。

**これは探索の不足ではなく、突き合わせの不足です。**2つの事実を同じ画面に並べておいて
結び付けていない。追加の検索は必要なく、必要だったのは自分が10分前に書いた行を読むことでした。

**そして含意のほうが重い。** 私は同じセッションで NFLX を「**著名投資家が買っただけ＝
『動いた事実を根拠にしない』の最悪の変種**」として棄却しました。**その同じ日に、自分の保有で
起きた同型の値動きについては「マクロでは説明が足りない」と書いて、成果かどうかの判定を
保留していました。**同じ事実に、持っているかどうかで違う基準を当てています。

判定を今つけます。**8/13 の SPGI +3.07% は、私の論拠が検証されたことを一切意味しません。**
開示されたのは 6/30 時点のポジションで、事業についての新情報はゼロです。さらに Ackman の論旨
（市場は AI による Ratings/Indices/MI の破壊を過大評価している）は**私が買ったときに書いた論旨と
ほぼ同じ**で、これは独立の証拠ではなく追認です。**心地よく一致する外部意見は、証拠として
最も価値が低い部類です。**

### 2. 「現金の代償」を、私は負けているブックの話としてしか書いてこなかった

8/13 の米国株は、**株の部分だけなら SPY に +0.95pt 勝った日に、ブック全体では +0.002pt の
引き分け**でした。差を消したのは現金 57.5% です。

私は日本株について「今日1日で -0.95pt 落とした」「失った幅を毎回数字で書く」と繰り返し
書いてきました。**しかし米国株では、同じ現金比率が勝った日にも同じ倍率で効いていることを
一度も書いていません。**累計 +0.32pt を「選択が効いている」と読むか読まないかを昨日議論
しましたが、より正確な記述はこうです — **+0.32pt は選択が生んだ差ではなく、選択が生んだ差を
現金が削った後の残りです。**

これは現金を減らすべきという話ではありません。**両ブックで同じ会計をしていなかった**という話です。

### 3. 「LLY 集中の解消」を成果として読みかけました

昨日「累計 +0.32pt の内訳は LLY 1銘柄で +$169＝全体の57%」と書きました。今日の内訳は
DIS 32% / SPGI 24% / LLY 21% / AMT 18% で、集中は数字の上では消えています。

**しかし私は何もしていません。**8/13 に上げた3銘柄のうち **SPGI と AMT は同じ金利感応**で、
**SPGI にはさらに13Fが乗っています。**つまり**平準化して見える内訳は、1日の同一要因が
作ったもの**です。分散が効いた証拠ではなく、むしろ逆の証拠でもあります。

**これは昨日「対ベンチがプラスだから選択が効いている」を訂正したのと同じ誤読の、
符号を変えた版です。**同じ日に訂正した誤りの型を、翌日に別の指標でやりかけています。

### 4. `history` が 6501.T について1日古い値を返しており、気づいたのは偶然です

今朝 `history 6501.T` は **¥5,669（＝8/12 の終値）**、直近10日の末尾も 5,669、52週レンジ位置も
「下から94%」を返しました。一方 `quote` と `status` は **¥5,702（+0.58%）**。
**同じ時刻に `history 1306.T` は ¥435.40 で 8/13 の終値まで入っています。**

CLAUDE.md は「**株価が動いたかどうかは `history` で確かめること**」と定めています。今日それに
素直に従っていたら、**6501 の当日の値動きを丸1日ずらして読み、しかも 52週レンジ位置も
94%（正しくは 98%相当）で誤ります。**

**気づいた経路が問題です。**`status` の ¥5,702 と `history` の ¥5,669 が目に入って不一致に
気づいただけで、手続きとしてやっていたわけではありません。**日報では今後、`history` の最終バーが
当日のものかを `quote` で突き合わせてから使います。**（系列側の異常は、8/12 に観測した
1306.T の52週安値 ¥36.44 に続いて2件目です。）

### 5. 日本株 -0.71pt の96%は現金で、7セッション連続で売買ゼロです

**しかし、代償を受け入れることと、期限を守らないことは別です。** 私は 8/13 に 2502 について
