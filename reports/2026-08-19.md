**以後、ザラ場セッションで「相対的にどう動いたか」から構造を結論するときは、

## 6. 運用者への報告（4件。うち1件は新規）

### 6-1. **【新規・計測の不整合】`snapshot` が、日本株を「保有は前日終値・ベンチは当日終値」で記録しました**

**8/19 の jp 行が、内部で日付の揃っていない価格で書かれています。**

| | `equity_log` 8/19 jp 行が使った価格 | 実際 |
|---|---|---|
| **6501（保有）** | **¥5,571.00 ＝ 8/17 の終値** | 8/18 終値は **¥5,514.00** |
| **1306.T（ベンチ）** | ¥431.00 ＝ **8/18 の終値** | ✓ |

結果、**記録された総資産 ¥19,981,103.17 は、正しい ¥19,958,303.17 より ¥22,800（+0.114pt）過大**です
（記録 -0.094% / 対ベンチ -4.41pt、正しくは **-0.209% / -4.52pt**）。

**原因は Yahoo 側の日本株データの遅延です。**私が 06:45 に `status` を流したとき、
`history 6501.T` は「1日 -3.4%・直近10日の末尾 5,571」——**8/17 の終値を最新として返していました。**
1306.T だけは 8/18 終値（¥431.00）に更新済みで、**同一セッション内で銘柄ごとに鮮度が違いました。**
**06:49 に再度 `quote` を流したところ両方とも 8/18 終値に更新されており、遅延は一過性です。**

**ただし `equity_log.csv` の行は書き直されませんでした。**`cmd_snapshot`（`broker.py:842-868`）は
同一日の行を除外して書き直す作りなので、**本日中にもう一度 `snapshot` が流れれば自動的に直ります。**
流れなければ **8/19 の jp 行は誤ったまま確定します。**

**私は `snapshot` を自分で流していません。**CLAUDE.md が挙げるコマンドに含まれておらず、
`accrue()` と `save()` を伴って state.json を書き換えるためです。**判断が要る箇所として報告します。**

**なお 8/19 の us 行と 8/18 の jp 行は整合しています**（前者は保有・ベンチとも 8/18 終値、
後者は両方とも 8/17 終値）。**壊れているのは 8/19 の jp 行1本だけです。**

### 6-2. 保有5銘柄すべてが「撤退未設定」で、後付けする手段がありません（4回目）

`--stop` は `buy` の引数のみです。**投資済み（米国42.3%・日本11.1%）に安全装置が効いていません。**
「売って買い直せば `--stop` を付けられる」という回避策は採りません——20時間クールダウンと
スリッページを払って制約を迂回する行為で、CLAUDE.md の「回避策を探すのではなく制約を受け入れる」に反します。
**4-3 に書いたとおり、この穴は LLY で実際に効き始めています。**

### 6-3. `screen` の決算ラベルが、将来の決算を「◯日後」と表示します（2回目）

`broker.py:585-587` で `days = (d - today).days`（`d` は**次回**決算日）としたうえ、
`0 <= days <= 7` の枝が `f"決算{days}日後"` を出しています。**`days` が正 ＝ 決算は未来なので、
正しくは「決算まで{days}日」です。**8/18 に CRM が `決算7日後` と表示されましたが、実際は **8/26 引け後 ＝ 7日“先”**。
`-3 <= days < 0` の枝（`決算{-days}日前に発表済`）は正しいので、**直すのは587行目の1箇所だけ**です。
**私は自分では直しません**（実験の途中で計測器を変えることになるため）。

### 6-4. `受取配当` が $0 のままです（6回目）

LLY の 8/14 権利落ち分 **$1.73 × 3株 ＝ $5.19** が未計上。
**8/26 に SPGI の権利落ち（$0.97 × 13株 ＝ $12.61）が来ます。**同じ経路なら取りこぼしが積み上がります。
`broker.py:336` の `d > since` と `:399` の `div_through = today`（JST）の組み合わせで、
**権利落ち日に JST 早朝のセッションが走ると、その日の配当は永久に対象外**になります。
同じ不等号がベンチ側（`:388`）にもあるため、**9月の SPY 権利落ちでは逆向きに歪む可能性があります。**
